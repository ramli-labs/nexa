  1. LANGKAH 01
    Aktifkan API
    Di Google Cloud Console: buat project, aktifkan Cloud Text-to-Speech API, lalu buat API key di menu Credentials.
  2. LANGKAH 02
    Tempel key
    Masukkan key di kolom bawah. Key disimpan hanya di browser ini (localStorage), tidak pernah dikirim ke tempat lain selain Google.
  3. LANGKAH 03
    Generate & dengarkan
    Tekan Generate semua. Setiap baris bisa diputar langsung; yang kurang pas tinggal diulang sendiri.
  4. LANGKAH 04
    Ekstrak ke game
    Unduh ZIP, ekstrak isinya ke assets/audio/voice/, buka game, jalankan VoiceManager.audit().

Catatan kuota: Google memberi gratis satu juta karakter per bulan untuk suara WaveNet dan empat juta untuk Standard, jadi seluruh naskah ini jauh di bawah batas gratis. Jika muncul pesan API key not valid atau blocked, cek bahwa Cloud Text-to-Speech API sudah diaktifkan dan pembatasan key mengizinkan domain ini. Alternatif tanpa browser: jalankan node assets/audio/voice/_google_tts.mjs dengan GOOGLE_TTS_KEY di environment.
