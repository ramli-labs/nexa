# voice / mentor

**Format:** mp3 80 kbps mono (atau .webm Opus 80 kbps). -16 LUFS, peak -1 dBFS, tanpa musik.

Nama file dikunci oleh `assets/js/voiceConfig.js` — cukup letakkan file dengan nama di bawah, tidak ada perubahan kode.

- `intro.mp3`
- `explanation.mp3`
- `explanation_02.mp3`
- `explanation_03.mp3`
- `reflection.mp3`
- `reflection_02.mp3`
- `unlock.mp3`
- `concern.mp3`
- `praise.mp3`
- `debrief.mp3`

File yang belum ada otomatis memakai fallback: subtitle + animasi per kata + SFX. Tidak ada error.
