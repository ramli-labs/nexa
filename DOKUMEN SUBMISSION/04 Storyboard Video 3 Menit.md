## Catatan Teknis Perekaman

| Aspek | Ketentuan |
|---|---|
| Resolusi rekaman | 1920×1080, 60 fps, peramban mode layar penuh |
| Zoom peramban | 100% — jangan ubah agar tata letak sesuai desain |
| Kursor | Tampilkan kursor; aktifkan sorot klik bila alat perekam mendukung |
| Audio gim | Rekam langsung dari gim, lalu turunkan ke −22 dB di bawah VO |
| Subtitle | CC gim tetap aktif + subtitle video terbakar untuk narasi |
| Kecepatan | Percepat maksimal 1,5× hanya pada pengisian slider/segel; interaksi kunci tetap kecepatan asli |
| Tempo VO | ± 145 kata/menit; total naskah ≈ 400 kata |
| Larangan | Jangan memotong popup proyeksi simulasi sebelum terbaca (bukti umpan balik konsekuensi) |
