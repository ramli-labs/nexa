ATURAN PRODUKSI KARAKTER
Setiap karakter dikirim sebagai satu file SVG per ekspresi (bukan spritesheet), viewBox="0 0 512 640", maksimum 40 KB setelah SVGO. Portrait bust dipakai di dialog bar; full-body hanya untuk NEXA di layar opening dan ending. Warna kulit/pakaian memakai currentColor + CSS custom property agar bisa diberi tint sesuai kondisi Future Balance.
